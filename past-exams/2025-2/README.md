## WARNING!
You must commit and push your work to the exam GitLab server, and ensure your
work is pushed successfully to the server **before the end of the exam**. You
must commit AND push your final work **5 minutes** prior to the deadline of the
exam. We can only mark what you have pushed. Anything that you forget to push
will be irretrievably lost.

You will be marked only on what has been pushed.

You must confirm your submission has been made correctly by checking the commit
and files on the Exam GitLab (e.g., using the browser and visit the web interface)
**within the exam time given**. To re-iterate, this means pushing your working
code continuously, and **much earlier** than the exact deadline. Pushing takes time
and network connections are often slower when it is close to the deadline, and
that is a factor you must consider and manage.

### Instructions
- Do not import non-standard Java libraries, except JUnit4.
- Your code must compile successfully to receive any marks.

- The files to be submitted are specified in each question.
  Note that the files should remain in their original locations in the
  repository (i.e., not moved or renamed), and any other files will not be
  included or considered during marking.

- A partially correct implementation will usually receive some marks.
  (i.e., if some test cases **that assess the correctness of the implementation**
  are provided, passing some tests usually indicates you may obtain some marks).
- There are exceptions, for example in cases where a "dummy" or "hardcoded"
  implementation always passes a certain test, there will be no marks if you ONLY
  pass that particular test. Marking test cases are different from the provided ones
  and marks are not necessarily proportional to the number of tests passed.

- Unless otherwise specified in the questions, you should write code only within the designated regions indicated by code comments in the provided files, and you must not create new methods or fields.

- In any case, your code must be buildable. If your code cannot run,
  you will receive zero marks for the question. Note that this could be caused by
  importing any non-default Java libraries/modules (except JUnit 4 or any
  provided libraries/modules) or changing the package header of a code file.
